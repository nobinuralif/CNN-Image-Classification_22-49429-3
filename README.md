# CNN Development on Custom Dataset

## Project Overview
This project develops a custom Convolutional Neural Network
(CNN) using PyTorch for multi-class image classification.

## Dataset
Intel Image Classification Dataset

Classes:
- Buildings
- Forest
- Glacier
- Mountain
- Sea
- Street

## Model Architecture
- 3 Convolutional Blocks
- ReLU Activation
- Max Pooling
- Fully Connected Layers
- Dropout (0.5)
- Adam Optimizer
- Cross Entropy Loss

## Training Configuration
- Image Size: 150 x 150
- Batch Size: 32
- Learning Rate: 0.001
- Maximum Epochs: 15

## Results
- Test Accuracy: 86.00%
- Validation Accuracy: 86.60%
- Macro F1-Score: 86.10%

- Python
- PyTorch

- Scikit-learn
